Описание

Набор реанимационный неонатальный для оказания скорой медицинской реанимационной неонатальной помощи предназначен предназначен для скорой медицинской помощи, включающей специализированную, на догоспитальном этапе при вызове по профилю, а также в условиях стационара. Представляет собой комплект инструментов, приборов и изделий, позволяющих подготовленному медицинскому персоналу оказывать скорую помощь на догоспитальном этапе.

Набор реанимационный неонатальный упакован в сумку медицинскую СМУ-01, СМУ-03 или в футляр-саквояж УМСП-02-Пм/2.

Сумка медицинская СМУ-01 изготовлена из синтетической ткани ПВХ 420Д раскрывается с помощью застежки-молнии и раскладывается на две одинаковые по толщине половины. Внутри сумки расположены вкладыши для размещения вложений. Сумка имеет две ручки для ношения одной рукой, ремень для ношения через плечо.
